<section id="motion" className="mb-16 scroll-mt-20 px-6">

<h1 className="mb-4 text-[32px] font-semibold leading-tight text-black dark:text-white">Motion</h1>

<p className="font-medium leading-6 tracking-[-0.1px] text-gray-200 dark:text-gray-100">
Motion controls the feel of the transition. It does not change how Laminar decides which glyphs or lanes survive a value update.
</p>

</section>

<section id="presets" className="mb-16 scroll-mt-20 px-6">

<h2 className="mb-4 text-[20px] font-semibold text-black dark:text-white">Presets</h2>

<p className="font-medium leading-6 tracking-[-0.1px] text-gray-200 dark:text-gray-100">
Text defaults to <code>default</code>. Numeric variants default to <code>snappy</code>. You can choose any preset explicitly.
</p>

```tsx
<Laminar text={label} animationPreset="default" />
<Laminar text={label} animationPreset="smooth" />
<Laminar text={value} variant="number" animationPreset="snappy" />
<Laminar text={score} variant="slots" animationPreset="bouncy" />
```

</section>

<section id="duration" className="mb-16 scroll-mt-20 px-6">

<h2 className="mb-4 text-[20px] font-semibold text-black dark:text-white">Duration</h2>

<p className="font-medium leading-6 tracking-[-0.1px] text-gray-200 dark:text-gray-100">
Use <code>animationDuration</code> to override the preset duration. The value is expressed in milliseconds.
</p>

```tsx
<Laminar
  text={status}
  animationPreset="smooth"
  animationDuration={420}
/>
```

</section>

<section id="stagger" className="mb-16 scroll-mt-20 px-6">

<h2 className="mb-4 text-[20px] font-semibold text-black dark:text-white">Stagger</h2>

<p className="font-medium leading-6 tracking-[-0.1px] text-gray-200 dark:text-gray-100">
Use <code>stagger</code> to delay glyph or digit animations across the value. The value is expressed in seconds and defaults to <code>0.02</code>.
</p>

```tsx
<Laminar
  text={score}
  variant="number"
  stagger={0.035}
/>
```

</section>

<section id="first-paint" className="mb-6 scroll-mt-20 px-6">

<h2 className="mb-4 text-[20px] font-semibold text-black dark:text-white">First paint</h2>

<p className="font-medium leading-6 tracking-[-0.1px] text-gray-200 dark:text-gray-100">
Laminar skips enter animations on first paint. The first value appears settled, and motion begins only after the value changes.
</p>

```tsx
<Laminar text="Ready" />
```

</section>
